# Rappels d'entretien : e-mails prêts à envoyer

Ces 4 e-mails s'envoient depuis **Resend → Broadcasts**, au segment des inscrits (`RESEND_SEGMENT_ID`).

| Fichier | Quand l'envoyer |
|---|---|
| `01-remise-en-route.md` | Fin mars (sud) / mi-avril (nord) |
| `02-ete-canicule.md` | Fin juin, avant les premières fortes chaleurs |
| `03-fin-ete.md` | Fin août |
| `04-hivernage.md` | Début octobre |

Pour chaque envoi :
1. Copiez l'objet et le texte dans un nouveau Broadcast.
2. Remplacez `https://www.piscinefacile.fr` par votre domaine si besoin.
3. Gardez le lien de désinscription en bas : `{{{RESEND_UNSUBSCRIBE_URL}}}` (obligatoire).
4. Envoyez-vous d'abord un test.
